# Lab 1 Overview

The purpose of this lab is to become familiar with Markdown and git for the needs of
this course.

The primary goals include:

- Editing a Markdown file
- Utilizing Markdown's various formatting features
- Learning to use Git/GitHub to manage a repository

## What is Markdown

**Markdown** is a markup language, _similar_ to HTML, where formatted text is
represented as a plaintext format. While HTML uses an XML-like structure for text,
markdown has a much more similified featureset.

## Steps to complete this lab

1. Create a new GitHub repository from the provided template repo
1. Clone your new repo locally with `git` or with the GH desktop application
1. Create the `lab1_overview.md` file within the `Lab 1` directory in the repo
1. Summarize this lab and steps required as part of the document
1. Demonstrate various markdown features
